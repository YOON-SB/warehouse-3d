# 창고 로봇 정책 3D 재생 + AI 운영 리포트

시뮬레이션 기록을 3D로 재생하고, LLM 리포터가 만든 `data/report.json`을
'AI 운영 리포트' 버튼에서 보여 줍니다.

## 리포트 바꾸는 법
1. Colab(LLM 리포터) 또는 `python run.py ... --report`로 새 report.json 만들기
2. 이 저장소의 `data/` 폴더 → Add file → Upload files → report.json 올리기 → Commit
3. 1~2분 뒤 페이지 새로고침 (화면 코드는 그대로, 리포트만 바뀜)
